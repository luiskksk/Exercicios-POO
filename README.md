# Exercicios-POO

Criar uma classe Livro com propriedades: Titulo, Autor, Ano. Adicione um método ExibirInfo() que imprime os detalhes do livro.

Criar uma classe Funcionario com encapsulamento no atributo Salario. Se o salário for negativo, mostrar mensagem de erro.

Criar herança:

Classe Veiculo com método Mover().
Classe Bicicleta que herda Veiculo e adiciona DarGrau().
Criar polimorfismo:

Classe Forma abstrata com método CalcularArea().
Criar Circulo e Triangulo que implementam CalcularArea().
